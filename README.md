# 🎨 Pictonary

Free, real-time online Pictionary for family & friends. Create a room, share the link, draw and guess. Anyone can play as a guest; signing in adds levels, ⭐ stars and power-up cards.

Built with **Svelte 5** + **Vite** on the front end and plain **WebSockets** for real-time multiplayer. The same game server runs on **Cloudflare Workers** (free, inside a Durable Object) or on **Node**.

## Features

- **Two game modes**
  - 🙋 **Every player**: everyone guesses, faster guesses score more, and the drawer earns points for each correct guess.
  - 👨‍👩‍👧‍👦 **Teams** (2–4 teams): teams take turns. Your teammates guess your drawing. Optional **steals** let other teams guess first and take the points.
- 💡 **Letter hints**: as the clock runs down, random letters of the word are revealed (0–5 hints, set by the host). Works in both modes.
- 🖌️ **Drawing tools**: 20 colors plus a custom color picker, 5 brush sizes, eraser, fill bucket, undo, and clear. Keyboard shortcuts `B` `E` `F` `1-5` `Ctrl+Z`.
- 🎯 3 word choices per turn (easy / medium / hard; harder words are worth more), **2,400+ family-friendly words** in 9 categories, plus **custom words** in any language. Words aren't repeated within a room until the pool runs out.
- 🔥 "So close!" hints for near-miss guesses. Correct guesses are hidden, and players who already guessed chat privately.
- 😂 Live emoji reactions, sound effects, a podium with confetti, and a team scoreboard.
- 📱 Works on phones, tablets and desktop. If you refresh or your Wi-Fi drops, you rejoin with your points intact.
- 👑 Host controls: settings, kick, skip turn, end game. If the host leaves, host passes to another player automatically.
- 👤 **Accounts** (username + password, no email): your level, XP, wins, correct guesses, drawings guessed and recent games are all saved. There's also a top-players board, and you can delete your account at any time.
- 🎴 **Power-up cards**, bought with ⭐ stars that are deliberately slow to earn. You can play 1 card per turn and 3 per game, and the host can switch cards off.

## Run locally

```bash
npm install
npm run build
npm start          # http://localhost:3000
```

For development with hot reload: `npm run dev`.

Accounts are stored in an embedded Postgres ([PGlite](https://pglite.dev)) under `data/`, so there's nothing to set up. Set `DATABASE_URL` to use a real Postgres database instead.

Run the multiplayer smoke test (with the server running): `npm test`.

To try it in Cloudflare's runtime instead: put `DATABASE_URL=…` in a `.dev.vars` file (git-ignored; leave it out to play as guests only), then `npm run cf:dev` (http://localhost:8787) and `URL=http://localhost:8787 npm test`.

## Word bank

`server/wordbank.json` is generated by `npm run words` (`scripts/build-words.mjs`) from free, open data:

- **[WordNet 3.1](https://wordnet.princeton.edu/)**: its categories and "is a kind of" tree keep only drawable things (mammals, birds, furniture, instruments, vehicles, buildings, jobs…).
- **[SCOWL](http://wordlist.aspell.net/)** word-frequency lists: these drop obscure words and set easy, medium and hard.
- **[LDNOOBW](https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words)**, plus our own blocklist, keeps it family-friendly.

The hand-picked lists in `server/words.js` are merged on top. To tweak the rules, edit the script and re-run it. The dictionary packages are dev-only, so deploys don't install them.

## Deploy (free)

**Cloudflare Workers** (free plan, never sleeps):

1. Create a free Postgres database on **[Neon](https://neon.tech)** (sign in with GitHub, then **New project**). Copy its connection string, which starts with `postgresql://…`.
2. In the Cloudflare dashboard go to **Workers & Pages → Create → Import a repository** and pick this repo. Build command `npm run build`, deploy command `npx wrangler deploy` (`wrangler.jsonc` has the rest). Every push to `main` redeploys.
3. In the Worker's **Settings → Variables and secrets**, add a **Secret** named `DATABASE_URL` with the Neon connection string.

Or from your own computer: `npx wrangler login`, `npx wrangler secret put DATABASE_URL`, then `npm run cf:deploy`.

How it fits the free plan: Cloudflare serves the site's files itself, one Durable Object (`GameServer`) holds every room in memory and runs the game clock, and the accounts API runs in the Worker. The free plan allows 100,000 requests a day (WebSocket messages count 20 to 1), which is plenty for family game nights. Watch usage under **Workers & Pages → pictonary → Metrics**. If a daily limit is ever hit, it resets at midnight UTC.

**Any Node host** (Render, Koyeb, Fly.io, Railway, a VPS): `npm ci --omit=dev && npm run build`, then `npm start` with `DATABASE_URL` set. `render.yaml` (Render blueprint) and a `Dockerfile` are included. Run only one instance, because rooms live in the server's memory.

## Project layout

```
server/   hub.js (connections & game messages), room.js (game engine), imposter.js, cards.js,
          words.js (word lists), accounts.js (accounts, stars, cards), api.js (REST API),
          db.js (schema), index.js + db-node.js (Node server: Express, ws, Postgres / PGlite)
worker/   index.js (Cloudflare Worker + GameServer Durable Object, Neon over HTTP)
shared/   constants.js (settings, teams, palette), powerups.js (cards & star economy)
src/      Svelte app: components/, lib/ (WebSocket client, game & account stores, canvas engine, sounds)
scripts/  smoke.js (end-to-end multiplayer test), build-words.mjs (word bank generator)
```
